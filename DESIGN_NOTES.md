# Campus Nova 11.0.0 Final

The existing Nova visual design is retained: light theme by default, dark theme support, modern university wordmark/login, large hero imagery, compact cards, clean spacing and the existing SPA navigation.

The final integration work is backend-first. The UI remains the same while the authentication/session layer is hardened for the real Moodle web-session chain.

The product target is functional parity with the original Campus where the actual Campus contracts are available, with controlled fallback instead of fabricated behavior for workflows whose execution contract has not been observed.
